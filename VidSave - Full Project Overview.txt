VidSave - Full Project Overview
VidSave යනු Facebook, YouTube, TikTok, Instagram, Twitter (X), Pinterest ඇතුළු සමාජ මාධ්‍ය රැසකින් වීඩියෝ සහ ඕඩියෝ (MP3) ඉතා පහසුවෙන් බාගත (Download) කරගත හැකි නවීන Full-Stack Web Application එකකි. SaveFrom.net වැනි ජනප්‍රිය වේදිකාවල ආභාෂය ලබා ගනිමින්, නවීන Glassmorphism UI මෝස්තරයක් සහ සර්වර් ඩිස්ක් ඉඩ නාස්ති නොවන සුවිශේෂී Direct Streaming Architecture එකක් සහිතව මෙය නිර්මාණය කර ඇත.

🌟 3. ප්‍රධාන විශේෂාංග (Key Features & Highlights)
🚀 Zero Server Disk Usage (සර්වර් ඩිස්ක් ඉඩ ඉතිරි කිරීම)
සාමාන්‍ය downloader වලදී වීඩියෝව මුලින්ම සර්වර් එකේ Hard drive එකට Save කර පසුව user ට යැවීම නිසා server disk එක පිරී යයි. නමුත් මෙහිදී 

streamVideoDownload()
 මඟින් yt-dlp හි stdout stream එක Node.js response (res) එකට කෙලින්ම pipe කර ඇත. එමගින් සර්වර් එකේ කිසිදු ෆයිල් එකක් තැන්පත් නොවී (Zero disk write) කෙලින්ම User ගේ Browser එකට download වේ.

🛡️ BotGuard & Anti-Blocking Bypass
YouTube සහ අනෙකුත් සේවාවන් මඟින් automated bots අවහිර කිරීම වැළැක්වීමට:

Customized User-Agent headers සහ Node.js JS runtime (--js-runtimes node) භාවිතය.
Multi-client impersonation (player_client=android,ios,web).
Session cookies inject කිරීමේ හැකියාව (

ytdlp_session_cookies.txt
 / YTDLP_COOKIES env var).
Cloud datacenter IP එකක් YouTube මඟින් block වුවහොත්, 

Instant Cloud Resolver & Mirror Fallback
 මඟින් oEmbed සහ cloud resolvers ඔස්සේ download පහසුකම අඛණ්ඩව ලබා දීම.
